Data Deletion

Effective September 26, 2026 · Contact: ylobodzynskyi@safeyourlove.com

Threadsignal does not currently create end-user accounts or store your submitted draft in its post database. Its local comparison database may contain Threads post text, URLs, handles, dates, and performance metrics.

Request deletion from the project operator

  1. Email ylobodzynskyi@safeyourlove.com with the subject Threadsignal data deletion.
  2. Include the Threads post URL, post ID, or other details needed to locate the record. Do not send a password, access token, or sensitive account credentials.
  3. We will confirm receipt and remove records we control within 30 days, or explain if we cannot identify them or must retain them for a legal reason.

If you run the application locally

Delete the local data/posts.json file to clear the stored comparison library. Draft text is not saved there. To remove content held by TypeSafe or Meta under their own policies, contact those services directly; deleting a local file does not delete their records.

This page is the data deletion instructions URL for the Threadsignal Meta app. It does not ask you to sign in.
